# Temporal demos — Unit 4b

Four build-an-explanation canvases (→/space forward, ← back, home/end jump, q closes;
`--save DIR` runs headless). No dependencies beyond the course base
(matplotlib, numpy, pandas; Builder comes from ../grammar).

| Script | Key concepts |
|---|---|
| `tp01_time_and_gaps.py` | Connection asserts continuity; gaps as claims (interpolate / break / zero); Cleveland's banking as branches |
| `tp02_many_series.py` | Superpose → small multiples → a horizon chart assembled band by band |
| `tp03_cycles.py` | Folding time at its true period; the overlay; the WRONG-period fold manufacturing pattern live |
| `tp04_change.py` | Raw vs indexed (two baselines!) vs log; rolling windows 3 vs 9; the connected scatter's seduction |

Each ends on the module's rule: a temporal chart owes four disclosures —
gap treatment, granularity, window, index baseline.
